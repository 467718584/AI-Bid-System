## 🔧 12:38 前端ES模块问题排查

### 问题
```
Uncaught TypeError: Failed to resolve module specifier "vue"
```

### 原因
- Python http.server无法处理ES6模块导入
- Vite开发服务器需要node_modules

### 当前状况
- WEI-PC上node_modules缺失
- npm install因网络问题失败
- Docker构建也因网络超时失败

### EdgeHub文件下发问题分析
- **命令长度限制**: Windows命令行最大约32KB
- **base64膨胀**: 文件base64后比原文件大约33%
- **650KB压缩包**: base64后约900KB，超出限制

### 解决方案
- 方案A: 本地npm install（需解决网络）
- 方案B: 使用Vite预览
- 方案C: Linux构建 + 导入到Windows
