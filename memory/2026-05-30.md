### ⚠️ 出现的错误

#### 错误1：swift-wh (CryptographyDeprecationWarning)
```
ramiko/transport.py:261: CryptographyDeprecationWarning: TripleDES has been moved to cryptography.hazmat.decrepit.ciphers.algorithms.TripleDES and will be removed from cryptography…
```
- **性质**: 警告（非致命错误）
- **影响**: 不影响系统运行，只是TripleDES算法被废弃
- **原因**: 某些依赖库（如paramiko）使用了废弃的加密算法
- **建议**: 后续更新依赖库版本

#### 错误2：mellow-c (Docker Permission Denied)
```
permission denied while trying to connect to the docker API at unix:///var/run/docker.sock
```
- **性质**: 权限错误
- **影响**: Docker命令无法执行
- **原因**: 当前用户不在docker用户组
- **解决方案**: `sudo usermod -aG docker $USER` 然后重新登录
