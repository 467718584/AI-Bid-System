## 🅰️ IVP - 工业视觉平台

| 端口 | 服务 | 说明 | 容器名 |
|------|------|------|--------|
| 5000 | MLflow | 机器学习实验跟踪 | industrial-vision-mlflow |

| 8080 | Frontend | Nginx前端 | industrial-vision-frontend |

### 前端
| 端口 | 服务 | 说明 |
|------|------|------|
| 3000 | Vue3 Frontend | Python http.server提供静态文件 |

| 端口 | 服务 | 说明 | 容器名 |
|------|------|------|--------|
| 5432 | PostgreSQL | 主数据库 | ai-bid-postgres |
| 6379 | Redis | 缓存 | ai-bid-redis |
| 8081 | User Service | 用户管理 | ai-bid-user |
| 8082 | Project Service | 项目管理 | ai-bid-project |
| 8083 | Material Service | 素材管理 | ai-bid-material |
| 8084 | Document Service | 文档管理 | ai-bid-document |
| 8085 | Bid Service | 投标管理 | ai-bid-bid |
| 8086 | Knowledge Service | 知识库(Python) | ai-bid-knowledge |

**Docker网络**: bid-network

### API网关路由规则
```
/api/user/*  → ai-bid-user:8081
/api/project/* → ai-bid-project:8082
/api/material/* → ai-bid-material:8083
/api/document/* → ai-bid-document:8084
/api/bid/* → ai-bid-bid:8085
```

## 🔧 常用命令

### 查看所有端口占用
```powershell
netstat -ano | findstr "LISTENING"
```

### 查看特定项目端口
```powershell
# IVP端口
netstat -ano | findstr "8080 8000 5000 9000 9001"

# AI-BID端口
netstat -ano | findstr "3000 5432 6379 8090 8081 8082 8083 8084 8085 8086 8087"
```

### 重启AI-BID服务
```powershell
cd C:\ai-bid
docker-compose restart
# 或单独重启
docker restart ai-bid-gateway
```
