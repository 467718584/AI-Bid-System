## ⚠️ Docker容器冲突警告

### 🔴 Redis端口冲突

| 容器 | 端口绑定 | 状态 |
|------|----------|------|
| ai-bid-redis | 0.0.0.0:6379→6379 | ✅ 运行中 |
| industrial-vision-redis | 0.0.0.0:6379→6379 | ❌ Exited |

**问题**: 两个Redis容器配置绑定相同宿主机端口6379，**不能同时启动**。

**影响**:
- AI-BID启动时占用6379
- IVP的Redis无法同时启动（端口被占用）

**解决方案**（选择一种）:

1. **方案A - 不同时运行两个项目**
   - 切换项目前先停止当前项目的Redis

2. **方案B - 修改IVP的Redis端口**（推荐）
   ```yaml
   # 修改 C:\ivp\docker-compose.yml
   redis:
     image: redis:7-alpine
     container_name: industrial-vision-redis
     ports:
       - "6380:6379"  # 改为6380
   ```
   同时修改IVP后端的 `REDIS_URL=redis://redis:6380/0`

3. **方案C - 共享Redis**
   - 让IVP使用AI-BID的Redis
   - 修改 `REDIS_URL=redis://host.docker.internal:6379/0`

## 🔧 常用命令

### 查看所有端口占用
```powershell
netstat -ano | findstr "LISTENING"
```

### 查看特定项目端口
```powershell
# IVP端口
netstat -ano | findstr "8080 8000 5000 9000 9001"

# AI-BID端口
netstat -ano | findstr "3000 5432 6379 8090 8081 8082 8083 8084 8085 8086 8087"
```

### 查看Docker容器
```powershell
# 所有容器
docker ps -a

# 仅AI-BID容器
docker ps -a --filter "name=ai-bid"

# 仅IVP容器
docker ps -a --filter "name=industrial-vision"
```

### 停止/启动Redis
```powershell
# 停止AI-BID Redis
docker stop ai-bid-redis

# 启动IVP Redis
docker start industrial-vision-redis

# 停止IVP Redis
docker stop industrial-vision-redis

# 启动AI-BID Redis
docker start ai-bid-redis
```

### 重启AI-BID服务
```powershell
cd C:\ai-bid
docker-compose restart
# 或单独重启
docker restart ai-bid-gateway
```
