## 遇到的问题汇总

### 1. Lombok 注解处理器不生效
**问题**：`maven-compiler-plugin` 配置了 `annotationProcessorPaths` 但Lombok注解（@Data, @Slf4j等）不生成代码
**原因**：Spring Boot BOM 管理的 Lombok 版本（1.18.32）与项目中指定版本（1.18.24）冲突
**解决**：在 common-core/common-security 等模块中显式添加 lombok 依赖，版本 1.18.30

### 2. Java 源选项版本错误
**问题**：`不再支持源选项 5。请使用 7 或更高版本`
**原因**：父 pom 的 `maven-compiler-plugin` 版本是 3.1（默认source=5），未正确继承Java 17配置
**解决**：在各模块 pom.xml 中显式添加 `maven-compiler-plugin` 配置，指定 source=17 target=17

### 3. javax.servlet vs jakarta.servlet
**问题**：`程序包javax.servlet.http不存在`
**原因**：Spring Boot 3.x 使用 Jakarta EE 9+（jakarta.servlet）而非 javax.servlet
**解决**：将 `javax.servlet.http.HttpServletRequest` 替换为 `jakarta.servlet.http.HttpServletRequest`

### 4. Feign 客户端依赖业务模块实体类
**问题**：`DocumentFeignClient` 引用了 `com.aidbid.document.entity.BidDocument`，造成循环依赖
**解决**：创建 DTO 类（DocumentDTO, MaterialDTO, ProjectDTO, UserDTO）替代实体类

### 5. Constants 类缺失
**问题**：`JwtUtils` 和 `JwtAuthenticationFilter` 引用不存在的 `Constants` 类
**解决**：在 common-core 中创建 `Constants` 类，包含 `TOKEN_PREFIX`, `JWT_SECRET_KEY`, `JWT_EXPIRE_TIME` 等常量

### 6. POM 文件配置问题
**问题**：
- ai-bid-gateway/pom.xml 缺少 `spring-cloud-starter-gateway` 版本
- ai-bid-material/pom.xml `<name>` 标签包含shell脚本无法解析
**解决**：手动修复这些 POM 文件

### 7. 包名不统一
**问题**：common-core 使用 `com.aibid.common`，但 ai-bid-xxx 模块代码使用 `com.aidbid.xxx`
**解决**：
- 在 common-core 中创建 `com.aidbid.common.core` 包及相关类（Result, PageResponse, BaseEntity, BusinessException, ResultCode, Constants 等）
- 将 ai-bid-user 模块的 import 从 `com.aibid.*` 改为 `com.aidbid.*`

### 8. Camunda BPM 依赖不可用
**问题**：Camunda BPM 依赖 `org.camunda.bpm:camunda-bpm-spring-boot-starter` 在 Maven Central 中不存在
**影响**：ai-bid-project 的 8 个 Listener 和 WorkflowService/Controller 使用 Camunda API
**临时方案**：创建了 stub 类（DelegateExecution, ExecutionListener）替代，但大量方法引用仍缺失

### 9. 缺失的实体类和DTO类
**问题**：ai-bid-project 模块代码引用了大量不存在的类：
- `com.aidbid.project.entity.Qualification`
- `com.aidbid.project.entity.EnterpriseInfo`
- `com.aidbid.project.entity.ProjectExperience`
- `com.aidbid.project.entity.FinancialData`
- `com.aidbid.project.entity.SkillDefinition`
- `com.aidbid.project.entity.SkillCatalog`
- `com.aidbid.project.dto.QualificationMatchRequest` 等
- `com.aidbid.project.service.QualificationService`
- `com.aidbid.project.service.WorkflowService`

**状态**：需要创建这些缺失的类，或从其他模块复制/重构
