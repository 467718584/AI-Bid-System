# 项目结构说明

## 概述

ai-bid-system 是一个基于 Spring Boot + FastAPI + Vue3 的智能投标系统，采用微服务架构。

## 模块分层结构

### Java 模块（标准四层架构）
```
Controller → Service → Mapper → Entity
```
- **Controller**: 处理 HTTP 请求，参数校验
- **Service**: 业务逻辑处理
- **Mapper**: 数据访问层（MyBatis-Plus）
- **Entity**: 数据库实体模型

### Python 模块（FastAPI 架构）
```
Router/API → Service → Repository/Client
```
- **main.py**: FastAPI 应用入口，路由定义
- **Service**: 业务逻辑封装
- **Client**: 外部服务调用（ChromaDB、LLM）

## 跨模块调用关系

```
前端 (Vue3)
  ↓ HTTP
API 网关 (Spring Cloud Gateway / Spring Boot)
  ↓ Feign / RestTemplate
  ├── 项目服务 (ai-bid-project:8081)
  ├── 材料服务 (ai-bid-material:8082)
  ├── 文档服务 (ai-bid-document:8083)
  ├── 用户服务 (ai-bid-user:8084)
  ├── AI 服务 (ai-bid-ai:8001) ← FastAPI
  └── 知识库服务 (ai-bid-knowledge:8002) ← FastAPI
```
