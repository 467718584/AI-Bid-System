## 1. 系统概述

### 1.1 项目背景

响应国家"人工智能+"战略（发改法规〔2026〕195号），构建一套集智能编制、精准质检、高效协同与知识管理于一体的投标文件编制系统，解决企业投标工作中存在的管理粗放、效率低下、质量不稳及合规风险高等核心痛点。

### 7.2 LLM网关设计

```python
class LLMGateway:
    """统一LLM网关"""
    
    def __init__(self):
        self.providers = {}
        self.default_model = 'minimax'
    
    def register_provider(self, name: str, provider: LLMProvider):
        self.providers[name] = provider
    
    def chat(self, messages: list, model: str = None) -> str:
        model = model or self.default_model
        return self.providers[model].chat(messages)
    
    def embed(self, texts: list, model: str = 'm3e') -> list:
        return self.providers['embedding'].embed(texts)
```

## 9. 安全设计

### 9.1 认证授权

```python
# JWT认证流程
"""
1. 用户登录 → 验证密码 → 生成JWT Token
2. 请求携带Token → 网关验证Token → 解析用户ID
3. 权限校验 → 业务处理
"""

# 权限校验流程
"""
1. 用户 → 角色列表 → 权限列表
2. 请求资源 → 资源所需权限 → 权限匹配
3. 匹配成功 → 允许访问
4. 匹配失败 → 拒绝访问
```
