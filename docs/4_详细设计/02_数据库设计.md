## 1. 数据库设计原则

### 1.1 命名规范

| 规范 | 示例 |
|------|------|
| 库名 | `ai_bid` |
| 表名单数 | `sys_user` |
| 字段小写下划线 | `created_at` |
| 主键字段 | `id` (UUID) |
| 外键字段 | `{table}_id` |
| 逻辑删除字段 | `deleted_at` |

### 1.2 通用字段

所有表均包含以下通用字段：

```sql
-- 通用审计字段
id VARCHAR(36) PRIMARY KEY DEFAULT gen_random_uuid()  -- UUID主键
created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP       -- 创建时间
updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP       -- 更新时间
deleted_at TIMESTAMP                                 -- 逻辑删除时间（为空表示未删除）
created_by VARCHAR(36)                               -- 创建人
```

### 1.3 设计标准

1. **事务支持**：所有业务表使用InnoDB引擎
2. **字符集**：UTF8MB4
3. **索引策略**：区分度高的字段建立索引
4. **外键约束**：推荐使用外键，但不过度依赖
5. **软删除**：使用 deleted_at 而非物理删除

## 3. 核心表结构设计

### 3.1 系统管理模块

#### 3.1.1 sys_user 用户表

```sql
-- 用户表
CREATE TABLE sys_user (
    id VARCHAR(36) PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    password VARCHAR(255) NOT NULL COMMENT '密码（BCrypt加密）',
    email VARCHAR(100) COMMENT '邮箱',
    phone VARCHAR(20) COMMENT '手机号',
    real_name VARCHAR(50) COMMENT '真实姓名',
    avatar_url VARCHAR(500) COMMENT '头像URL',
    status INT DEFAULT 1 COMMENT '状态：1-正常 0-禁用',
    last_login_at TIMESTAMP COMMENT '最后登录时间',
    last_login_ip VARCHAR(50) COMMENT '最后登录IP',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    deleted_at TIMESTAMP,
    created_by VARCHAR(36),
    CONSTRAINT uk_sys_user_username UNIQUE (username),
    CONSTRAINT uk_sys_user_email UNIQUE (email)
);

-- 索引
CREATE INDEX idx_sys_user_status ON sys_user(status);
CREATE INDEX idx_sys_user_phone ON sys_user(phone);

COMMENT ON TABLE sys_user IS '用户表';
COMMENT ON COLUMN sys_user.username IS '用户名（登录账号）';
COMMENT ON COLUMN sys_user.password IS '密码（BCrypt加密存储）';
COMMENT ON COLUMN sys_user.status IS '状态：1-正常 0-禁用';
```

```sql
-- 自动更新updated_at触发器函数
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = CURRENT_TIMESTAMP;
    RETURN NEW;
END;
$$ language 'plpgsql';

-- 应用触发器（为所有业务表创建触发器）
CREATE TRIGGER update_sys_user_updated_at BEFORE UPDATE ON sys_user
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_sys_role_updated_at BEFORE UPDATE ON sys_role
    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

-- 等等...为其他表创建相同的触发器
```

### 6.3 视图脚本

```sql
-- 用户完整信息视图
CREATE OR REPLACE VIEW v_sys_user_full AS
SELECT 
    u.id, u.username, u.email, u.phone, u.real_name, u.status,
    u.last_login_at, u.last_login_ip, u.created_at,
    array_agg(r.role_name) as roles,
    array_agg(r.role_code) as role_codes
FROM sys_user u
LEFT JOIN sys_user_role ur ON u.id = ur.user_id
LEFT JOIN sys_role r ON ur.role_id = r.id
WHERE u.deleted_at IS NULL
GROUP BY u.id;

-- 项目状态统计视图
CREATE OR REPLACE VIEW v_bid_project_stats AS
SELECT 
    project_status,
    count(*) as total_count,
    sum(bid_amount) as total_amount
FROM bid_project
WHERE deleted_at IS NULL
GROUP BY project_status;

-- 资质过期预警视图
CREATE OR REPLACE VIEW v_qualification_expiring AS
SELECT 
    q.*, e.enterprise_name,
    q.expire_date - CURRENT_DATE as days_to_expire
FROM enterprise_qualification q
JOIN enterprise_info e ON q.enterprise_id = e.id
WHERE q.valid_status IN ('VALID', 'EXPIRING')
    AND q.deleted_at IS NULL
    AND e.deleted_at IS NULL
ORDER BY days_to_expire;
```
