**LLM网关架构：**

```python
# LLM Gateway 设计
class LLMGateway:
    def __init__(self):
        self.providers = {
            'minimax': MinimaxProvider(),
            'deepseek': DeepSeekProvider(),
            'qwen': QwenProvider()  # 本地部署预留
        }
    
    def chat(self, model: str, messages: list, **kwargs):
        # 支持模型切换
        return self.providers[model].chat(messages, **kwargs)
    
    def embed(self, texts: list, model: str = 'm3e'):
        # 向量化接口
        return self.providers['embedding'].embed(texts)
```
