## 1. 产品概述

### 1.1 产品定位

本产品是一款面向企业投标团队的 **AI智能投标文件编制管理系统**，旨在通过人工智能技术赋能投标全流程，实现：

```
┌────────────────────────────────────────────────────────────────┐
│                    产品核心价值                                 │
├────────────────────────────────────────────────────────────────┤
│  🎯 降本增效      →     AI自动生成，减少人工投入               │
│  📊 质量提升      →     标准化模板+合规检查，提高中标率         │
│  🧠 知识沉淀      →     企业级知识库，资产持续复用              │
│  ⚡ 效率倍增      →     流程自动化，缩短编制周期                 │
│  🛡️ 风险控制      →     自动检测废标项，降低废标风险           │
└────────────────────────────────────────────────────────────────┘
```

### 1.2 目标用户

| 用户群体 | 使用场景 | 核心诉求 |
|----------|----------|----------|
| 投标负责人 | 统筹投标项目 | 实时掌握进度、协调资源、把控风险 |
| 技术/商务编标人员 | 编制标书 | 快速获取素材、高效完成编制 |
| 审核人员 | 审核标书 | 快速定位问题、确保合规 |
| 行政/财务 | 辅助支持 | 数据统计、文档管理 |

### 3.1 企业知识资产模块（F1-F3）

#### 3.1.1 素材库

**功能描述：**
建立支持分级分类管理的企业级知识库，用于存储、积累和管理标准技术方案等可复用素材。

**功能列表：**

| 功能编号 | 功能名称 | 优先级 | 描述 |
|----------|----------|--------|------|
| F1.1 | 素材分类管理 | P0 | 多级分类体系，支持自定义标签 |
| F1.2 | 素材上传录入 | P0 | 支持Word/PDF/图片格式 |
| F1.3 | 素材编辑操作 | P0 | 修改标题、内容、标签 |
| F1.4 | 素材检索筛选 | P0 | 分类+标签+关键词检索 |
| F1.5 | 素材切片预览 | P1 | 按章节/段落智能切片 |
| F1.6 | 私人图库 | P1 | 个人图片管理与智能处理 |
| F1.7 | 文档抽图 | P2 | 自动提取文档图片 |
| F1.8 | 图片主题识别 | P2 | 自动打标分类 |

**业务规则：**

| 规则 | 说明 |
|------|------|
| 上传限制 | 单文件 ≤ 50MB，支持 doc/docx/pdf/jpg/png |
| 分类层级 | 最多支持4级分类 |
| 标签数量 | 每个素材最多20个标签 |
| 切片长度 | 每片 300-500字符 |

**数据模型：**

```json
{
  "material": {
    "id": "string",
    "title": "string",
    "category_id": "string",
    "file_type": "enum[WORD,PDF,IMAGE]",
    "file_url": "string",
    "tags": ["string"],
    "description": "string",
    "chunk_count": "int",
    "created_by": "string",
    "created_at": "datetime",
    "updated_at": "datetime"
  }
}
```

## 输出要求
1. 使用Markdown格式
2. 包含适当的章节编号
