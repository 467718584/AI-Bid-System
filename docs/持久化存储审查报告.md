## 一、标书存储 (ai-bid-bid 服务)

### 问题发现 ❌ CRITICAL
**标书数据使用内存存储，未持久化到数据库！**

位置：`ai-bid-bid/src/main/java/com/aidbid/bid/controller/BidController.java`

```java
private final List<Map<String, Object>> bidStore = new ArrayList<>();
```

**影响**：服务重启后数据丢失（昨晚6条 → 今早2条）

### 正确的持久化位置（应为）
- 数据库表：`bid_project` (已创建但空着)
- Entity类：缺失
- Mapper/Repository：缺失

### 建议修复
1. 创建 `BidProject` Entity 映射 `bid_project` 表
2. 创建 `BidProjectMapper` 
3. 将 `BidController` 中的 `bidStore` 替换为数据库操作
