## 4. AI质量评估

### 4.1 技术标生成质量评估

**评估维度：**

| 维度 | 权重 | 评估标准 |
|------|------|----------|
| 内容相关性 | 30% | 内容与招标要求匹配度 |
| 技术准确性 | 25% | 技术方案专业性、准确性 |
| 格式规范性 | 20% | 格式符合投标规范 |
| 原创性 | 15% | 内容重复率 < 15% |
| 可读性 | 10% | 表达清晰、逻辑连贯 |

**评估方法：**

| 维度 | 评估方法 |
|------|----------|
| 内容相关性 | 人工评审：对比招标文件要求 |
| 技术准确性 | 人工评审：技术专家审核 |
| 格式规范性 | 自动化：格式检查工具 |
| 原创性 | 自动化：文本相似度检测（<15%） |
| 可读性 | 自动化：语言复杂度分析 |

**质量评分公式：**

```
总分 = 相关性×0.3 + 准确性×0.25 + 规范性×0.2 + 原创性×0.15 + 可读性×0.1
```

**质量等级：**

| 等级 | 分数范围 | 说明 |
|------|----------|------|
| 优秀 | 90-100 | 可直接使用 |
| 良好 | 75-89 | 少量修改后可使用 |
| 一般 | 60-74 | 需要较多修改 |
| 较差 | < 60 | 需要重新生成 |

### 4.2 RAG检索质量评估

**评估指标：**

| 指标 | 计算方法 | 目标值 |
|------|----------|--------|
| 召回率@K | 检索结果中相关文档的比例 | ≥ 85% |
| MRR | 首个相关文档的排名倒数 | ≥ 0.8 |
| NDCG@K | 归一化折损累计增益 | ≥ 0.8 |
| 相似度阈值 | 相关文档的平均相似度 | ≥ 0.7 |

### 4.3 招标文件解析准确率

| 解析项 | 准确率目标 |
|--------|-----------|
| 项目名称 | ≥ 95% |
| 联系人信息 | ≥ 90% |
| 时间节点 | ≥ 95% |
| 评标办法 | ≥ 85% |
| 废标条款 | ≥ 90% |

## 6. 缺陷管理

### 6.1 缺陷等级定义

| 等级 | 说明 | 响应时间 | 修复时间 |
|------|------|----------|----------|
| P0-严重 | 系统崩溃、数据丢失、核心功能不可用 | 1小时 | 4小时 |
| P1-高 | 重要功能失效、业务流程阻塞 | 4小时 | 1天 |
| P2-中 | 功能缺陷、交互问题 | 1天 | 3天 |
| P3-低 | UI问题、建议改进 | 3天 | 1周 |

### 6.2 缺陷状态

| 状态 | 说明 |
|------|------|
| New | 新建缺陷 |
| Open | 确认打开 |
| In Progress | 修复中 |
