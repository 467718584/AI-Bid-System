# AI-Bid-System 修复日志

## 2026-05-27 23:50

### 问题描述
ai-bid-user 服务启动失败：
```
java.lang.IllegalArgumentException: Invalid value type for attribute 'factoryBeanObjectType': java.lang.String
```

### 错误分析
这是 MyBatis-Plus 与 Spring Boot 3.x 的已知兼容性问题。当 Spring 尝试创建 MapperFactoryBean 时，MyBatis-Plus 3.5.6+ 应该已经支持 Spring Boot 3.x，但可能存在配置问题。

### 可能原因
1. @ConfigurationProperties 绑定问题
2. MyBatisPlusAutoConfiguration 中的 factoryBeanObjectType 处理不当
3. MapperScan 配置问题

### 尝试的修复方案

1. **方案1：排除 MyBatisPlusAutoConfiguration**
在主类或配置类上添加：
```java
@SpringBootApplication(exclude = {MyBatisPlusAutoConfiguration.class})
```

2. **方案2：降级 MyBatis-Plus 版本**
将 mybatis-plus-boot-starter 从 3.5.6 降级到 3.5.5

3. **方案3：添加配置类**
创建配置类处理 MapperScan 问题
